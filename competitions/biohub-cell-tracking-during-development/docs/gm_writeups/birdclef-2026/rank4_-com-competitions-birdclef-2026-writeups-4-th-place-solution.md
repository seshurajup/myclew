# BirdCLEF 2026 — 4th Place Solution

Thanks to all of our teammates! We're glad to see no shake-down — many public top-10 teams dropped significantly, and fortunately we had selected our highest private LB submission.

## Overview

Our solution is a 5-model ensemble combining a Perch v2 bioacoustic foundation model, two custom-trained SED (Sound Event Detection) models, and two Perch-distilled SED models. We leveraged pretrained XC backbones from the BirdCLEF 2025 2nd place solution, Perch knowledge distillation, and multi-model blending with taxonomic post-processing.

## Training Details

### perch
We used the [Google Perch v2](https://www.kaggle.com/models/google/bird-vocalization-classifier/TensorFlow2/perch_v2) bioacoustic foundation model directly without any fine-tuning. It serves as both a standalone predictor and a prototype ranker in the ensemble.

### v2s
Our baseline SED model:
- **Backbone**: EfficientNetV2-S-IN21K with pretrained weights from the [BirdCLEF 2025 2nd place solution](https://www.kaggle.com/competitions/birdclef-2025/writeups/volodymyr-vialactea-2nd-place-journey-down-the-rab), fine-tuned on 2026 competition data with a 234-class head
- **Data**: Competition train + soundscapes (5× upsampled) + external data (iNat/XC, threshold=100 per species)
- **Augmentation**: Audio-level mixing (50%), frequency filter SpecAug disabled

we start with Starry's [BirdClef 2025 code](https://github.com/StarrySky-SHT/BirdClef2025-8thSol). First of all, the 2021/22/23/24 data was used to pretrain the SED model (tf_efficientnetv2_b3 backbone) with BCE loss. It scored ~0.897. The parameters I used: mel_bin: 192 f_min/f_max: 40/140000 n_fft: 2048 win_length/hop_size: 1024/512 train/infer durations: 10/5s

#### public LB improvement journey (single model, Running time: ~20min)
| Methods | Scored |

### v2s_2025_2nd
We reproduced the [2025 2nd-place SED architecture](https://www.kaggle.com/competitions/birdclef-2025/writeups/volodymyr-vialactea-2nd-place-journey-down-the-rab) with minimal modifications for 2026:
- **Backbone**: EfficientNetV2-S-IN21K, structure and pretrained weights both from 2025 2nd place
- **Loss**: Focal BCE (α=0.25, γ=2.0)
- **Augmentation**: STFT-based random frequency filtering, frequency/time masking, half-proportion audio mixing
- **Converted to OpenVINO** IR format for CPU-efficient inference on Kaggle

### v2s_perch_distill & se26_perch_distill (Perch Knowledge Distillation)

This pipeline is modified from [tuckerarrants' public code](https://www.kaggle.com/code/tuckerarrants/bc2026-distilled-sed?scriptVersionId=315112860). And we do some slightly modification.

These models are trained to simultaneously classify bird species AND align with [Perch v2](https://www.kaggle.com/models/google/bird-vocalization-classifier/TensorFlow2/perch_v2) embeddings:

**Architecture**:
- SED backbone (EFv2-S or SeriesResNext26d) + additional distillation projection head (Linear → 1536-dim Perch embedding space)
- Generalized Mean pooling (learnable exponent) for frequency aggregation
- Temporal attention + classification heads

## Ensemble & Post-Processing

### Ensemble Weights
| Group | Models | Inner weight | Outer weight |
|---|---|---|---|
| perch | perch | — | **0.40** |
| SED blend | v2s | 0.70 | 0.26 (total) |
| | v2s_2025_2nd | 0.30 | |
| PDENS blend | v2s_perch_distill | 0.25 | 0.34 (total) |
| | se26_perch_distill | 0.75 | |

**Blend strategy**: Rank-gating composite — perch serves as a species ranking prototype that gates SED confidence scores, preventing weaker SED models from introducing false positives in rare species.

### Post-Processing Pipeline
1. **Genus smoothing** (α=0.12): Species within the same taxonomic genus have probabilities smoothed toward each other — helps co-occurring related species
2. **Time-of-day prior** (α=1.0): Per-species hourly activity distributions applied to all predictions
3. **Sonotype mirroring**: Synthetic sound variants share the max prediction of their group
4. **Fat-tail temporal smoothing**: Kernel radius=3, weights ∝ distance^{-1.5}

## Inference Pipeline (Kaggle CPU-4 Constraint)

All inference runs within Kaggle's 4 vCPU limit using a dynamic CPU-budget scheduler:

```
Budget: 4 vCPU total, 2 vCPU per lane

Timeline:
[0s]   perch (2 CPU) + v2s_perch_distill (2 CPU) → start together
[Xm]   perch done → v2s starts (2 CPU)
[Ym]   v2s_perch_distill done → v2s_2025_2nd starts (2 CPU)
[Zm]   v2s done → se26_perch_distill starts (overlaps v2s_2025_2nd tail)
[Wm]   All done → BLEND
```

v2s_2025_2nd is served via OpenVINO for CPU-efficient inference; perch via ONNX Runtime.

## What Didn't Work

- **Self-trained XC pretraining**: We attempted to pretrain our own backbone on 814K XC recordings (~7,489 species) from scratch. Results were consistently worse than directly using the pretrained weights from the [2025 2nd place solution](https://www.kaggle.com/competitions/birdclef-2025/writeups/volodymyr-vialactea-2nd-place-journey-down-the-rab).
- **Standard pseudo-labeling**: Using ensembled SED model outputs as soft labels for soundscape segments did not improve performance. Only Perch-based pseudo labels (from the foundation model) led to meaningful gains.
- **AnuraSet external data**: Including frog recordings from AnuraSet caused a slight LB drop due to domain mismatch.
- **External data threshold >100 per species**: Marginal improvement vs. added noise.

There maybe something we lose. Feel free to ask any questions!
