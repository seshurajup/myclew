- **Motivation:** pilkwang's detector trains at `(1,4,4)` (≈1.63 µm isotropic). A `(1,2,2)` detector
  halves XY spacing (≈0.81 µm) → sharper peaks in dense regions → higher edge-precision → adj_edge.
  baseline_v1's EQUAL-budget A/B was inconclusive: (1,2,2) LOST (official 0.6086 base / 0.7919 richaug
  vs (1,4,4) 0.8249) but purely from UNDERTRAINING — the 4×-voxel detector's recall collapsed 0.98→0.70
  at max_iters=300/es-ep11 (`docs/baseline_v1_1_exp_result.md`). This removes that confound: both
  resolutions get a fair converged budget with richaug (v1-proven +0.1833) folded in.
- **Claim (falsifiable):** with a converged budget (max_iters 1000, patience 12, cosine+warmup) and
  identical richaug, **(1,2,2) v2_2 > (1,4,4) v2_1** on golden-12 official adjJ.
- **Expected signal + direction:** v2_2 − v2_1 official adjJ **> 0** (expect +0.005..+0.02 if the
  localization lever is real); v2_2 node_recall recovers to ≳0.95 (no undertraining collapse); the
  densest embryos (44b6_12dfb391, 6bba_05db0fb1) improve most.
- **Measurement:**
  - RESOLUTION contrast → **NOT bracket-screened** (a 5-epoch mini rung under-serves a late-converging
    finer detector). Both arms are **full converged** golden-12 runs.
  - Final judge: **golden-12 official** adjJ on `splits_ft.json` (`predict_and_score_v2.sh --exp-id EXP-001`).
  - Density-changing? **yes** → any gain over pilkwang 0.8708 is **NEEDS-LB** (human submits; never us);
    the v2_2−v2_1 delta itself is CV-judgeable.
- **Decision rule:** accept the (1,2,2) lever iff **v2_2 official > v2_1 official** beyond fold-to-fold
  noise; if v2_2 ≈/< v2_1 even converged, DROP the resolution lever. (v2_3 convergence-aid only if
